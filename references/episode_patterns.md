# 集数识别正则表达式参考

本文件供 AI 在处理集数识别时参考，列出各类常见格式的正则表达式。

---

## 带季号的完整格式

```regex
# S01E01 / s01e01 / S1E1（最常见）
[Ss](\d{1,2})[Ee](\d{1,3})

# 1x01（西剧常见）
(\d{1,2})x(\d{2,3})

# S01E01-E03（多集合并）
[Ss](\d{1,2})[Ee](\d{1,3})[-~][Ee](\d{1,3})

# S01E01E02（连写多集）
[Ss](\d{1,2})[Ee](\d{1,3})[Ee](\d{1,3})
```

## 仅集号格式（无季号）

```regex
# EP01 / Ep.01 / E01
[Ee][Pp]?\.?(\d{1,3})

# 第01集 / 第1集
第\s*(\d{1,3})\s*集

# 01话 / 第01话（动漫常见）
第?\s*(\d{1,3})\s*[话話]

# Episode 01（英文完整写法）
[Ee]pisode\s+(\d{1,3})

# 纯数字（需排除年份等干扰，通常两到三位）
(?<!\d)(\d{2,3})(?!\d)
```

## 季号单独识别

```regex
# Season 01 / Season 1（文件夹名）
[Ss]eason\s+(\d{1,2})

# S01（简写）
[Ss](\d{1,2})(?![Ee])

# 第一季/第二季（中文，需映射）
第([一二三四五六七八九十百]+)季

# 第1季/第01季
第(\d{1,2})季
```

## 特别篇关键词正则

```regex
(?i)(特别篇|SP\d*|Special|OVA\d*|OAD|番外|花絮|幕后|Making\s*Of|预告|Trailer|PV\d*|\bOP\d*\b|\bED\d*\b|NCOP|NCED|采访|访谈)
```

## 识别优先级

1. 文件名中的 `SxxExx` 格式（最高优先级）
2. 文件名中的 `NxNN` 格式
3. 父文件夹名称中的季号信息
4. 文件名中的纯集号格式（`EP01`、`第01集`等）
5. 纯数字（最低优先级，可能误判）

## 典型文件名示例与解析

| 原始文件名 | 识别结果 | 说明 |
|-----------|----------|------|
| `布鲁伊.S01E01.mkv` | S01E01 | 标准格式 |
| `[ANi] 布鲁伊 - 01 [1080P].mkv` | S01E01（默认S01） | 纯集号，无季信息 |
| `Bluey.2x05.mkv` | S02E05 | 西剧格式 |
| `布鲁伊.第03集.mp4` | S01E03（默认S01） | 中文集号 |
| `布鲁伊.SP01.mkv` | 特别篇 → Season 00 | SP 关键词 |
| `布鲁伊.OVA.1080p.mkv` | 特别篇 → Season 00 | OVA 关键词 |
| `布鲁伊.圣诞特别篇.mkv` | 特别篇 → Season 00 | 特别篇关键词 |
| `Season 2/布鲁伊.E05.mkv` | S02E05 | 从父文件夹取季号 |
